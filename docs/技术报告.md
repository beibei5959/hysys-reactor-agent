# 技术报告：AI 驱动的 HYSYS 反应器智能选择系统

（考核交付物 4：技术报告，1-2 页）

## 1. 任务与目标

在装有 Aspen HYSYS V15 的 Windows 工作站（远程访问）上构建 AI 系统：接收用户对反应过程的
自然语言描述 → 自主判断应使用的反应器类型 → 在 HYSYS 中正确创建/配置该反应器 → 返回模拟
计算结果。考核要求至少处理三个场景：甲烷蒸汽重整、甲苯歧化、水煤浆气化。

## 2. 系统架构

系统分两层。**原始 agent 层**提供：自然语言入口（`app.py --query/--input`）、反应器选型规则
（`reactor_rules.py`）、参数校验（`validate_input`）、真实 COM 适配器（`com_client.py`）、
mock 模式与 Web 前端。**集成层**（本次交付扩展）提供：中文题目确定性路由（`run_nl.py` +
`scenario_presets.py`）、Equilibrium/Gibbs 真机分派（`verified_runners.py` + `hysys_tools.py`）、
两个独立真机验证脚本（`reforming_mvp/`、`gasification_mvp/`）。

调用链：中文题目 → run_nl.py（关键词命中预设→固定结构化参数提交；未命中回退 LLM 提取）→
app.py（校验→选型→分派）→ COM（GetActiveObject）→ HYSYS 求解 → 自动验算 → result.json
（含选型理由、中文原题、真机案例路径、逐项检查）。

## 3. 选型方法论

与考核参考逻辑一致的三条规则：给定转化率 → Conversion；路径已知且可逆、受热力学平衡控制 →
Equilibrium；多反应且路径/产物分布未知 → Gibbs。三场景分别命中：甲苯歧化（明确 50% 转化率）→
Conversion；甲烷重整（主+副两可逆反应、问不同温度平衡组成）→ Equilibrium；水煤浆气化（复杂
多反应、产物分布难预测）→ Gibbs。每份结果附自然语言选型理由。

## 4. 真机验证方法论

- **写前守卫**：场景 2 在写入任何进料前核对案例身份、组件、物性包、反应计量、转化率设置与流股
  连接，任一不符即拒绝写入（不污染参考案例）；
- **连续稳定判据**：轮询中连续 3 次全部检查通过才报成功（严于单次读取），并同时要求 solver 空闲；
- **衡算闭环**：场景 2 质量残差 0.0 kg/h、化学计量残差 ≤ 比例容差；场景 3 元素衡算残差 ~3e-8；
  场景 1 两工况平衡商与平衡常数吻合至 ~1e-8；
- **留档**：三场景均 SaveAs 保存 .hsc，录屏覆盖"输入→命令→HYSYS→结果"全过程。

## 5. 探索过程与关键决策

1. **确定性路由而非纯 LLM 提取**：校验层对 Equilibrium 强制要求平衡方法、场景 2 守卫要求精确
   摩尔流（1e-7 容差），LLM 自由提取不稳定；故中文题目先走关键词→固定预设，原文仍保留为
   user_query，未命中查询仍回退 LLM 路径，能力不缩水。
2. **场景 2 复用已验证参考案例**：通用 COM 从零建模路径中，仅"既有甲苯参考案例拼接序列"经过
   真机严格验证；故 Conversion 通道在该案例上完成进料写入/求解/12 项验算（已如实标注
   execution_mode），场景 1/3 则为完全自动从零建模。
3. **场景 1/3 以子进程调用独立验证脚本**：两脚本各自含严格检查与 3 次稳定判据，独立可复跑；
   agent 负责选型、分派、结果归一与答复组织，符合"agent 调工具"范式且失败可定位。
4. **网页演示保持 mock**：考核未要求网页接真机；Web 后端当前为代码级固定的 Mock 通道
   （接真机不是配置开关，需另行开发）；mock 页面显著标注"未接 HYSYS"，真机演示走
   远程工作站 CLI 链路。接真机网页列为可选增强（需额外开发与端到端验证），不在本次交付内。

## 6. 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| `GetActiveObject` 报 Operation unavailable | 脚本依赖**运行中**的 HYSYS；修正操作指引为保持 HYSYS 打开 |
| 冷启动会话首个案例不求解（读到 -32767） | 预热会话（先打开案例）后复跑通过 |
| "适配器仅支持连接诊断"误报 | `supports_simulation` 仅在 connect() 之后可信，调整检查顺序 |
| 10000/92.14 ≠ 10×参考摩尔流 | 以 HYSYS 实际摩尔质量 92.1408 精确换算 108.52955420760267 kmol/h |
| 场景 2 报"请激活 toluene_python_test.hsc" | 运行前确认标题栏案例身份；多实例怀疑经排查为案例未切换 |

## 7. 结果摘要

| 场景 | 反应器 | 关键结果 | 判据 |
|---|---|---|---|
| 1 重整 | Equilibrium | 710℃ 转化 55.06%、600℃ 30.22%；平衡商≈K（~1e-8） | 全检查 true，3 次稳定 |
| 2 甲苯 | Conversion | 进料 10000.0 kg/h、转化率 50.0%；苯 27.1324、邻二甲苯 27.1338 kmol/h；质量残差 0.0 | 12 项全 true |
| 3 气化 | Gibbs | 碳转化率=CO 收率 40.86%；气相 CO:H2=50:50（剩余固碳 30.53 kmol/h 单列）；元素残差 ~3e-8；热负荷 6.29e6 kJ/h | 全检查 true，3 次稳定 |

## 8. 假设与偏差

二甲苯归并邻位（参考案例限制）；重整仅题目给定两反应；气化将煤视为纯固体碳、产物物种不含
甲烷、按 1000 kg/h 浆料比例基准验证（**未**换算题目 80000 Nm³/h 的绝对产量）；CO:H₂=50:50
为气相比例（剩余固碳单列）；10000 kg/h = 已验证参考流精确 10 倍；场景 2 复用参考案例而非
从零建模；收敛采用连续 3 次稳定判据。以上均同步标注于 README 与结果 limitations 字段。
