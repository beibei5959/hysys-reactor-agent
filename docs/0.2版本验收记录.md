## 在线冒烟验证

新版本通过任务入口提交“甲苯转化率80%，温度873.15 K，绝压2000 kPa，其余参数未提供”。本次将请求上限设为15秒、任务预算90秒：本地解析超时，DeepSeek解析成功；本地解释超时，DeepSeek解释成功。结果正确保存为 needs_input，未调用模拟器。此状态是预期的缺参分支，不是运行失败。

历史三场景及硅基流动实际调用记录来自0.1版本；本轮不把旧记录描述为0.2的全面在线验证。

## 可交付边界

交付内容为受控单机 Python 后端及可安装软件包，不包含前端。并发上限和模型熔断属于同一服务对象；SQLite 支持本机进程共享任务状态，不支持把数据库放到网络共享盘冒充多机协调。进程崩溃后需要查询任务并显式恢复，没有后台任务调度系统。

真实建模、求解、收敛检查与结果 API 尚未集成；真实模式在模型请求与 COM 写操作之前阻断。该限制没有通过删除错误提示掩盖。未来接入真实计算时仍需独占 HYSYS Worker、案例隔离、操作核对、许可证及真实三场景验收。

客户端模型超时取消的是等待，不承诺停止供应商计算或计费。通用同步执行器不能强制取消卡住的外部 COM 调用，本版没有对外暴露该能力。日志与任务库的访问权限和备份需要由部署环境管理。
