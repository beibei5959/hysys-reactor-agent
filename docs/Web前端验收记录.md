# Web 前端验收记录

日期：2026-10-03。

下文记录初次发布状态。后续交互修订及最新测试见《Web交互修订验收记录.md》，其中本地模型等待上限已调整为15秒。

## 实现范围

React + TypeScript + Vite 页面，独立 Python FastAPI 接口。本机账号密码登录、退出与持久化会话；任务访问控制；自然语言和结构化示例提交；分析后人工参数确认；修订历史；Mock 运行；中文结果与导出；桌面及窄屏布局。

既有后端未修改。提交前以 `work/backend-before-web.json` 的 SHA256 基线逐文件核对。

## 验证记录

- Python：原后端81项 + 新接口7项，共88项测试通过。
- 接口：三个场景稳定选出 Equilibrium / Conversion / Gibbs；确认前无模拟结果，确认后实际调用 Mock；同键不重复执行、输入冲突拒绝、账号隔离、CSRF、退出撤销会话、缺参数、持久化与未知结果禁止重跑、登录失败限流通过。
- 浏览器：5项端到端测试，覆盖登录退出、运行模式说明、三个场景的实际点击流程、缺参数补充、刷新恢复、JSON下载及390像素窄屏导航。
- 构建：TypeScript 类型检查及 Vite 生产构建通过。Python 新代码 Ruff 检查与格式化通过。
- 在线自然语言：本地 `qwen/qwen3.5-9b` 超时约60秒，随后 DeepSeek `deepseek-v4-flash` 约14.5秒成功解析；规则选择 Conversion，并停在缺参数状态，没有误执行模拟。此次请求未触发第三供应商；不能据此声称硅基流动在本次 Web 联调中已实测。
- DeepSeek 专项复验：使用现有配置单独调用同一模型，解析约7.5秒成功、中文解释约4.5秒成功。
- 完整在线任务复验：对上述网页任务补齐参数并确认，任务最终为 `completed`，解释为 `success`，模拟来源为 `mock`；解释阶段本地模型约60秒超时后，DeepSeek 约6秒成功接替。解析和解释都验证了实际降级链路。服务可用性是本次实测结果，不表示第三方服务永远不会故障。

## 未宣称完成的事项

真实 HYSYS 反应器对象的创建、写入和真实三场景计算尚未验证。本次 Mock 端到端通过只表示页面、接口、任务与调用链连通，不是工程计算精度验收。Web 服务是单机单进程版本，未进行跨实例一致性测试或高并发压测。

默认登录仅在本机 HTTP 使用；外部部署需要 HTTPS、实际 Origin 和 Secure Cookie 配置。没有硬编码默认口令；本机预览账号随机生成，凭据与数据库均排除出发布压缩包。
