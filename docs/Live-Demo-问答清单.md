# Live Demo 问答清单（演示备稿）

## 一、演示流程（现场 10 分钟版）

1. 打开远程工作站，HYSYS 保持运行：
   - 场景 2 前置：Window 菜单**激活** `toluene_python_test.hsc`，核对标题栏；
   - 场景 1/3 前置：无需打开案例（脚本自建），运行期间**不要点击 HYSYS**；
2. 终端现场跑（顺序建议 2 → 1 → 3，每条约 1-2 分钟）：
   `python -X utf8 run_nl.py queries\scenario2_toluene.txt`（其余同理）；
3. 指认证据三点：`PRESET_MATCHED`、`EXIT_CODE: 0`、result.json 里的
   `selected_reactor` / `selection_reason` / `user_query`（中文原始描述）/ 真机溯源字段
   （场景 2 `case_unique_id`，场景 1/3 `report_path`）；
4. HYSYS 里打开对应案例展示 flowsheet 与结果表；
5. 备胎：远程机连不上 → 放录屏（HYSYS_delivery/recordings/）+ 网页 Mock 演示交互流程。

## 三、高危提问与标准回答

1. **"这是真 HYSYS 算的吗？"**
   是。证据链：录屏三点自检（单独跑仿真脚本产生不了 PRESET_MATCHED 和 agent 层字段）；
   result.json 有真机案例路径；三个 .hsc 留档可当场打开。

2. **"场景 2 为什么复用参考案例，不从零建模？"**
   通用 COM 建模路径中只有这条参考序列经过真机严格验证（12 项检查），为可靠性优先采用；
   结果里如实标注 `execution_mode: existing_reference_case_update`；场景 1/3 是完全自动从零建模。

3. **"10000 kg/h 怎么换算的？"**
   已验证 1000 kg/h 参考流的精确 10 倍 = 108.52955420760267 kmol/h
   （按 HYSYS 实际摩尔质量 92.1408，不是 92.14 粗算）。只改广延量，强度量检查全部保持。

4. **"任务书要求苯+三种二甲苯，你只有邻二甲苯？"**
   参考案例组分限制，间/对异构体归并为邻二甲苯——已在 README 第 5 节作为偏差披露；
   化学计量与质量衡算仍严格闭合（残差 0.0）。

5. **"80000 Nm³/h 合成气对上了吗？"**
   没有换算绝对产量。当前按 1000 kg/h 浆料（62 wt%）比例基准验证，碳转化率/CO 收率是
   强度量与基准无关——已披露，不回避。

6. **"CO:H₂=50:50，为什么摩尔分数只有 29%？"**
   两种口径：50:50 是**气相**比例；`outlet_mole_fractions` 把剩余固体碳（30.5258 kmol/h）
   计入分母。结果里固碳单列，不可混读。

7. **"LLM 提取参数不稳定怎么办？"**
   三个基准场景走确定性关键词→固定预设路由，不经过 LLM 提取；LLM 只是未命中查询的回退路径。
   原文仍作为 user_query 全程保留。

8. **"网页是真算吗？"**
   不是。Web 后端为代码级固定的 Mock 通道，页面显著标注"未接 HYSYS"；真机演示走 CLI。
   接真机网页需要另行开发+端到端验证，列为可选增强。

9. **"怎么判断收敛？"**
   连续 3 次轮询全部检查通过（results_stable）+ solver 空闲，比单次读取严格。

10. **"AI 在开发里起了什么作用？"**
    人工主导架构设计、框架选型与验证判据；Codex / Claude Code 两个 AI 助手在人工指令下
    分别完成框架搭建与三场景真机验证实现、排障和文档初稿，所有结论经人工复核并以
    result.json / .hsc / 录屏闭环。详见 docs/AI开发记录_时间线.md"AI 协作方式说明"。
