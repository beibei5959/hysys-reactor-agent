# HYSYS Automation 增量验证脚本

## 使用说明

在远程考试机上运行（Python 3.12.4 + pywin32 + Aspen HYSYS V15 已打开）。

**运行前**：确保 HYSYS 已打开，且至少有一个活动案例（可以是空白案例）。

## 脚本顺序

| 脚本 | 用途 | 写操作 | 前提 |
|---|---|---|---|
| `01_probe_connection.py` | 只读连接诊断 | 否 | HYSYS 已打开 |
| `02_explore_object_model.py` | 探索 COM 对象模型（列出所有属性/方法） | 否 | 有活动案例 |
| `03_create_case_and_components.py` | 创建新测试案例 + 添加组分 | 是（新建案例） | 02 结果 |
| `04_property_package.py` | 配置物性包 | 是 | 03 完成 |
| `05_create_streams.py` | 创建进料/出料物流 | 是 | 04 完成 |
| `06_create_reactions.py` | 创建反应和反应集 | 是 | 04 完成 |
| `07_conversion_reactor.py` | 创建 Conversion 反应器、运行、读结果 | 是 | 05 + 06 完成 |

## 关键原则

1. 每个脚本独立运行，失败时记录错误信息
2. 所有脚本操作**新建的测试案例**，不影响手动建立的甲苯歧化案例
3. 脚本中发现的 COM API 路径需要记录在 `api_evidence.md` 中
4. 不猜测 API——如果某个方法不存在，用 `dir()` 探索替代方案
